Kirim klaim ke mesin audit

Sisi rumah sakit: SIMRS faskes mendorong klaim baru ke SiKePo lewat POST /api/ingest/claims dengan header X-API-Key. Klaim langsung diaudit pipeline A1 Triage → A2 Investigator → A3 Adjudicator (Ling 3.0 Flash Sante) begitu diterima, skor risiko dan rekomendasi kembali dalam hitungan detik.

Formulir pengiriman klaimidempoten per SEP

API key dikelola Super Admin di Cockpit › Users › API Ingest Faskes. Key terikat satu faskes, klaim untuk faskes lain akan ditolak 403.
